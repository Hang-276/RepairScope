# GS监督对象与方法主张核对

日期：2026-10-18。依据当前源码与 [Stage1终局记录](STAGE1_RESULT.md)，仅做定义和推导，不修改算法、不采集、不训练、不新增效果实验。以下命题是条件结论；反例不是本轮观测到的真实任务。

## 1. 当前实现究竟监督什么

`repairscope/decision.py::goal_sufficiency_loss`用完整离线真实效用形成教师q；受限效用由真实oracle patch在选中字段上替换前态、未选字段保留前态后计算。Predictor的真实预测Patch与Goal heads明确不参与这项GS损失。

因此它是“oracle输出更新范围能否保留候选偏好”的监督。它可以奖惩漏掉目标输出的Scope，但目标输出已入选时，不检验预测该输出所需输入条件是否充分。真实动力学仍由基础Patch等损失学习。Scope门的STE使离散选择具有代理反向路径，不改变这个监督对象。

## 2. 饱和命题及证明

**假设。** 一个有效候选组中，教师与受限偏好在相同温度tau>0下分别为q=softmax(U/tau)、p=softmax(U_scope/tau)。教师停止梯度，使用当前实现的KL(q||p)，没有其他项混入被审计的独立GS梯度。各效用有限，Scope代理反向导数有限。

**命题。** 若各候选的受限效用与完整效用相等，或只相差所有候选共同的常数，则GS为0，且GS对Scope选择器的梯度为0（忽略数值舍入）。

**证明。** softmax对公共常数平移不变，所以p=q，KL为0。对任一候选a的受限效用求导得到 `(p(a)-q(a))/tau=0`。继续对任意Scope分数或参数使用链式法则，零上游梯度乘任意有限代理导数仍为零。采用直通估计或有限差分系数不能将这个零梯度变成非零。证毕。

这说明Stage1的8组饱和符合当前定义，不是要求再修浮点精度。follow约1.49e-8的KL不应当作可用信号。命题只约束满足假设的组和参数状态，不证明所有数据或整个训练过程恒零。static prior只是排名的一项，不是字段永久入选的硬规则。

## 3. 输出覆盖不保证输入条件充分：条件反例

**假设。** 状态包含二值条件c和目标字段y，初始y=0，目标为y'=1。两个候选动作分别产生 `a0: y'=c`、`a1: y'=1-c`，成本相同。所选S包含y、不包含c。比较c=0与c=1两种状态时，S、S内输入、动作和所有可传给受限预测器的其他信息相同；不允许借Scope身份、风险旁路或额外摘要传递c。

**命题。** 当前oracle GS在两种状态都可为0，但任何仅依据上述相同受限输入的确定性候选排序器不能在两种状态都正确。

**证明。** y在S内，oracle patch把各候选的真实y'直接提供给受限效用，所以每种状态的受限效用等于完整效用，按上一命题GS为0。当c=0，a1优于a0；当c=1，a0优于a1。受限排序器对每个候选看到的输入跨两种状态相同，只能给出相同排序，因此至少一种状态错误。证毕。

这证明oracle目标本身不强制输入依赖充分；它不证明Stage1的Predictor错误由遗漏c造成。fresh未训练误差、动力学未学会和输入遗漏必须分别识别。

## 4. 将反例用于当前架构前还需哪些限定

当前架构不是一个已经证明只读取S的系统：选择器在Top-k前编码候选；关系块对有效交互作硬Scope限制；Patch输出用布尔Scope控制；可靠性头会池化Scope内外特征。Schema、复制槽、历史、候选检索和Scope身份也可能携带信息。

因此上节的“其他信息相同、没有旁路”假设不能自动套到现有端到端控制器。字段预算也不等于真实观测或计算减少。方法修订前应画清可见输入、交互、输出及风险评分的所有路径，并明确预算控制的对象，不能仅用一个输入遮罩就宣称信息论保证。

## 5. 方法选择与最小设计要求

| 路线 | 合理主张 | 当前缺口 |
| --- | --- | --- |
| 保留现有oracle GS | 目标输出更新覆盖/候选偏好保持的辅助正则 | Stage1没有初始覆盖缺口；其他损失改变Scope后是否有防遗忘收益未测试，不能称已证明决策充分性收益 |
| 改为预测充分性目标 | 所选上下文支持真实预测与动作选择 | 需要解决动力学误差混杂、教师质量、Scope梯度及信息旁路，是方法修订 |
| 结束当前v2方向 | 保存工程与负向准入证据 | 不再把增加同类数据当成创新或验证 |

当前决定是停止现有v2正式实验，保留上述选择的区别。若继续研究，优先完成第二条的最小设计，再决定是否实施；本文件不替它提供新实验或预算授权。

预测充分性设计至少明确以下四项：

1. **监督对象。** 离线真实效用可作教师；学生必须与实际受限预测/部署决策相连。若使用学习教师或Goal head，须说明误差、训练来源与可被利用的捷径，不能把oracle真值继续填入学生结果。
2. **实际Scope路径。** 当前关系键mask和Patch应用使用布尔Scope。仅把GS里的oracle patch换成预测patch，可能只训练Predictor而没有进入selector的梯度。必须审计实际输入交互与输出门到scope logits/参数的独立路径；硬前向仍守预算，软反向及额外计算明确记账。
3. **误差区分。** 分开目标输出漏选、预测条件漏选、动力学未学会及检索不可达。不能让fresh模型的错误自动被归因为Scope；也不能用另一个未验证头的改进代替部署决策改进。
4. **可证伪条件。** 在固定合法任务分布、相同公开信息/容量/成本和预冻结规则下检验。需要区分能与不能识别上述误差的证据；先写清失败后如何结束，不能按GS正负补样本或为了非零梯度改prior/B。

本次推导不提供新方法的收敛、泛化、梯度无偏或整体安全保证。对应定义、可实现路径和证据条件未完成前，不改Proposal为已验证结果，不启动v2.1训练。
