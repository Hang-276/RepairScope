# 从旧 RepairScope 迁移到 RepairScope-Evo

迁移日期：2026-10-17（北京时间）。当前工作版本为 `repairscope 0.2.0`，研究标题为 RepairScope-Evo。

## 最终范围决定

用户明确表示“之前的工作已经废弃了，直接改成新的就可以”，并要求仓库保持公开以便服务器直接 clone。因此新工作树替换旧四态预测系统，不同时维护两套方法。旧代码、协议和结果可从 Git 历史检索，不继续作为当前可执行入口。

提案中“保留旧文件”的建议被上述后续明确指令覆盖；原提案作为来源文档保留，不能将它误当作高于当前用户请求的操作指令。

GitHub 地址继续为 `Hang-276/RepairScope`，展示标题采用 RepairScope-Evo，无需改变远端路径即可直接克隆。仓库可见性按本次实时核验为 public；提案中的“私有仓库”是先前报告的历史表述。本次不将仓库改为 private。

## 旧状态的含义

| 旧项目 | 迁移处理 |
|---|---|
| 四态 effect/scalar predictor 与 4B 训练 | 废弃；当前工作树不再提供旧实现 |
| 旧 GATE 2 | `superseded_before_completion` |
| 旧全量 capture、采标签与旧比较 | 不自动继续 |
| 旧工程测试数量和环境验收 | 保留历史含义，不作为新方案方法有效性的证据 |

`superseded_before_completion` 表示研究方向在旧验证完成前发生替换，既不表示旧方案已通过，也不表示已被证伪。旧报告没有被改写成新研究结果。
