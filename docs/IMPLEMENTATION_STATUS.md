## 当前实现的具体限制

P1 读取服务器导出的已有自然轨迹、候选和原任务成绩；当前包不重新实现原生在线 Actor 或 capture。原成绩原样保存，影子分支不替换它。

更新回归检查覆盖此前已接受的自然见证前缀，分别重放原固定程序和新知识生成的行为；尚未穷举重放所有历史条件变体。完整反事实记录仍保留，报告明确标记这项覆盖限制，进入 P2 前需审查相关条件反例的覆盖。

机制数量按程序和条件查询的归一化结构去重，避免换实体或机制名称增加数量；结构差异仍需语义审计，不能自动证明是两类不同机制。P1 入口输出继续审查建议，不自动启动 P2。

运行日志及终端摘要使用英文，详细行为约束见 [English run logs](LOGGING.md)。CPU 进程时间和 GPU 忙时/峰值未由当前编排器测量时明确记为未测量，不由墙钟估算成实测。

## 需要服务器完成的接入与验收

真实执行依赖现有 AppWorld 0.2.0 环境、冻结 Qwen3-8B-AWQ 服务、真实 train 轨迹、D1 目标和重放 receipts。这些资产不包含在公开包中。当前包尚不驱动原生在线 Actor/capture；完整既有轨迹、1–4 个实际候选和原任务计分结果须由服务器操作者按 [操作说明](SERVER_RUNBOOK.md) 导出。输入清单、版本、hash、服务完整锁定与隔离重放均须依据服务器实际文件配置和检查；不能合成缺失资产。

`configs/evo_v1.yaml` 使用 JSON 语法保存冻结协议。`configs/assets.example.json` 只有占位路径，`configs/events.example.json` 是故意为空、无法通过真实运行校验的外壳；二者不构成可运行实验数据。

旧服务器已验收的 C1–C7 行为没有被当作新代码自动继承的事实。新入口不重置、重配或重新安装服务器服务，也不在没有实际 receipt 的情况下声称 32000 上下文、截断或重放行为已成立。

真实机制证据要求经审计的 invariant checker、合法且可比较的条件干预、完整目标向量、实际语义差分和隔离分支。缺少可靠映射时记 `unknown`；格式正确与文件齐全不解决语义有效性。

知识修订检查拟议规则的实际注入及当前生成行为；旧证据同时检查旧固定程序和新知识在旧上下文中重新生成的程序，全部分支和模型成本计费。留出行为状态不参与对应更新决策，迁移改善须有真实来源、变更规则实际注入、新旧知识提示 hash 差异和程序行为变化。所有配对保留。只有真实 P1 A/B/C 均满足且逐任务人工编辑为零，才能建议进入 P2。当前没有这种科学结论。

每阶段最多 15 个自然状态，每任务最多两次实际知识学习事件；额外状态仍核验并保留候选见证，不发起新的联合学习。当前记录分支身份及 `cache_key`，但尚未实现重放缓存；所有实际分支均计费，缓存命中数为 0。
